# پلیر آوا · AVA Player

برنامهٔ دسکتاپ فارسی برای پنج لاین مستقل پخش روی نمایشگرهای ویندوز. نسخهٔ 0.1.0، مناسب آزمایش اولیه؛ پیش از استفاده در اجرای زنده روی سخت‌افزار مقصد تست کنید.

## اجرا و ساخت نصاب

Windows 10/11 x64 و Node.js 24 یا جدیدتر:

```powershell
npm ci
npm start
npm test
npm run dist:win
```

خروجی: `dist/AVA Player Setup 0.1.0.exe`. نصب با انتخاب مسیر و میان‌بر دسکتاپ؛ آیکن و صفحهٔ شروع آوا. نصاب بدون امضای دیجیتال است؛ امضای رسمی به گواهی ناشر نیاز دارد. گردش‌کار `.github/workflows/windows.yml` تست و ساخت دستی/درخواست ادغام را انجام می‌دهد. با ارسال تگ نسخه، `.github/workflows/release.yml` روی Windows نصاب را می‌سازد و آن را در بخش Releases به صورت نسخهٔ آزمایشی منتشر می‌کند. دانلود نسخهٔ اولیه از صفحهٔ [Releases](https://github.com/hassandana1371-hub/ava-player/releases/tag/v0.1.0) پس از موفق‌شدن گردش‌کار انجام می‌شود؛ دسترسی مخزن تغییری نمی‌کند.

## روش کار

1. در تنظیمات Windows، نمایشگرها را روی **Extend** قرار دهید. لاین‌ها را به نمایشگرهای دلخواه اختصاص دهید. رزولوشن از ویندوز خوانده می‌شود، از جمله نمایشگرهای با DPI متفاوت؛ برنامه رزولوشن سیستم را تغییر نمی‌دهد.
2. از «افزودن فایل» یا کشیدن فایل از Explorer به بانک استفاده کنید.
3. فایل بانک را روی پیش‌نمایش لاین بکشید، یا فایل را انتخاب و روی پیش‌نمایش کلیک کنید. خروجی فعلی تغییر نمی‌کند.
4. با «ارسال به خروجی» فایل آماده را پخش کنید. کنترل‌های پخش، مکث، توقف/بازگشت، زمان، تکرار و سیاه‌کردن برای هر لاین مستقل‌اند.
5. انتخاب اندازه: حفظ نسبت با حاشیه، پرکردن با برش، یا کشیدن تا لبه‌ها. خروجی یک پنجرهٔ تمام‌صفحه در ابعاد نمایشگر است.
6. «صدای این لاین» فقط یک لاین را از کارت صدای پیش‌فرض ویندوز پخش می‌کند. پیش‌نمایش و پنجره‌های خارجی بی‌صدا هستند تا صدا چندبار پخش نشود. انتخاب دستگاه صوتی از تنظیمات ویندوز انجام می‌شود.

انتخاب یک نمایشگر در چند لاین مجاز است؛ آخرین پنجره/ارسال روی بقیه قرار می‌گیرد، ترکیب یا تقسیم تصویر انجام نمی‌شود. Escape در پنجرهٔ خروجی آن را می‌بندد. اگر میز کنترل زیر خروجی اصلی پوشانده شد، Escape یا Alt+Tab بزنید. تغییر اتصال نمایشگرها خودکار شناسایی می‌شود؛ خروجی نمایشگر جداشده بسته می‌شود.

## قالب‌ها

- MP4/MOV/M4V/WebM/MKV با کدک‌های قابل پخش در Electron؛ توصیه MP4 با H.264/AAC. پسوند به تنهایی تضمین‌کنندهٔ پخش نیست؛ ProRes/HEVC و DRM تضمین نمی‌شوند. خطای پخش در خود لاین نمایش داده می‌شود.
- PNG/JPEG/WebP/BMP و GIF. GIF با سرعت داخلی خودش پخش می‌شود و مکث/Seek و Loop خاموش برای آن اعمال نمی‌شود؛ برای کنترل زمانی آن را به ویدئو تبدیل کنید. عکس ثابت تا تعویض فایل روی خروجی باقی می‌ماند.
- MP3/WAV/OGG با کنترل صدا.
- PDF چندصفحه‌ای با زمان قابل تنظیم هر اسلاید و تکرار.
- PPT/PPTX از طریق **LibreOffice نصب‌شده** در مسیر پیش‌فرض؛ فایل به PDF محلی تبدیل می‌شود. انیمیشن، صدا و ویدئوی داخل پاورپوینت حفظ نمی‌شود. جایگزین: از PowerPoint خروجی MP4 یا PDF بگیرید. بدون LibreOffice، پیغام واضح نمایش داده می‌شود و بقیهٔ واردکردن فایل‌ها ادامه پیدا می‌کند.

## ذخیره و محدودیت‌ها

بانک و تنظیمات در `session.json` داخل پوشهٔ userData برنامه (در ویندوز معمولاً `%APPDATA%/ava-player`) ذخیره می‌شوند؛ فایل‌های اصلی کپی نمی‌شوند و باید در مسیر قبلی بمانند. خروجی‌های تبدیل‌شده در همان پوشهٔ داده ذخیره می‌شوند. اجرای بعدی بانک را برمی‌گرداند ولی عمداً خروجی خارجی و پخش خودکار را فعال نمی‌کند. حذف از بانک فایل اصلی را حذف نمی‌کند.

این نسخه پخش یک فایل در هر لاین دارد؛ playlist خودکار، زمان‌بندی، ترکیب لایه‌ها، نگاشت هندسی LED و همگام‌سازی فریم‌دقیق ندارد. کنترل‌ها با زمان مشترک هماهنگ می‌شوند اما چند خروجی frame-locked نیستند. هر لاین حداکثر سه Decode (نهایی میز، پیش‌نمایش، خروجی خارجی) می‌خواهد؛ پنج خروجی 4K به GPU، کدک و توان خروجی مناسب نیاز دارد. این تعداد خروجی برای تلویزیون‌ها علاوه بر نمایشگر کنترل باید توسط سخت‌افزار و ویندوز پشتیبانی شود.

## توسعه و آزمایش

از همین checkout استفاده کنید؛ برای کارهای معمول worktree نسازید. برنامه با Electron، sandbox و contextIsolation اجرا می‌شود. رسانه‌ها فقط از شناسه‌های ثبت‌شدهٔ محلی خوانده می‌شوند؛ محتوای HTML به عنوان فایل قابل پخش پذیرفته نمی‌شود.

```sh
npm test
npm run smoke
```

آزمون smoke اجرای واقعی Electron را در حالت headless آزمایش می‌کند: ورود PNG، MP4 دارای صدا و PDF، پنج لاین همزمان، Cue/Take، مکث، صدا، تغییر اندازه، دو پنجرهٔ خروجی روی یک نمایشگر، قطع نمایشگر شبیه‌سازی‌شده، سیاه‌کردن و بازگردانی نشست. فقط در این آزمون Linux از `--no-sandbox` و GPU نرم‌افزاری استفاده می‌شود؛ این گزینه‌ها در اجرای عادی برنامه فعال نیستند. تصویر تست در `test-results/control.png` ایجاد می‌شود. پنج نمایشگر واقعی، صدای فیزیکی، عملکرد 4K، تبدیل Office و نصب روی ویندوز باید روی سیستم مقصد تأیید شوند.

فونت Estedad با مجوز OFL همراه برنامه است؛ متن مجوز در `assets/OFL-Estedad.txt`. نشان SVG از مخزن سایت آوا گرفته شده و آیکن برنامه نسخهٔ سادهٔ حروف آواست.

### ساخت مستقیم NSIS روی Linux

اگر Wine روی میزبان کار نمی‌کند، با NSIS 3 معتبر می‌توان نصاب را مستقیم ساخت. این مسیر امضای دیجیتال ایجاد نمی‌کند؛ برنامهٔ بسته‌بندی‌شده همان نسخهٔ Electron است. مقدار `NSIS_MAKENSIS` باید به کامپایلر Linux بستهٔ رسمی NSIS اشاره کند (ابزار دریافت‌شده با checksum توسط electron-builder نیز مناسب است):

```sh
npm run dist:win:dir
NSIS_MAKENSIS=/path/to/nsis/linux/makensis npm run installer:nsis
```

نصاب مستقیم، نصب برای کاربر فعلی، انتخاب مسیر، میان‌بر دسکتاپ/منوی شروع و حذف برنامه از Settings را فراهم می‌کند. حذف‌کننده فقط فایل‌های بسته را حذف می‌کند و دادهٔ بانک در AppData را نگه می‌دارد.
